<a id="herramientas-utilizadas"></a>
## 🛠️ Herramientas Utilizadas
* **Java (JDK 17)**: Lenguaje principal aplicado para la resolución de ejercicios del Paradigma Orientado a Objetos.
* **JUnit**: Framework utilizado para la implementación de pruebas unitarias y desarrollo guiado por pruebas (TDD) en Java.
* **Eclipse**: Entorno de desarrollo (IDE) utilizado para la edición, depuración y estructuración del código.
* **SWI-Prolog**: Entorno y compilador empleado para la programación declarativa basada en lógica de predicados.
* **Haskell (GHC / GHCi)**: Compilador e intérprete utilizado para la resolución de ejercicios bajo el Paradigma Funcional.
